# Copyright and takedown requests

if you made a mod (or own the rights to something in a listing) and you don't want it on Branch, or something about it is wrong, you can ask for it to be changed or removed.

## how to send a request

1. open the mod in Branch.
2. press **Report** and pick **Copyright or permission issue**.
3. in the details, say what you own (the mod, art, code), what you want changed (remove the listing, stop hosting the file, fix the credit), and how the admin can check you're the owner, like a link to your GitHub or mod page that matches the listing.
4. add contact info so the admin can reply.

## what happens next

- the admin reviews every copyright report.
- while a report is being checked, the admin can turn off the download or hide the listing.
- if the request checks out, the listing is removed or fixed.

## how Branch handles permission

giving credit doesn't count as permission to share someone's file. Branch only hosts a copy of a mod when the author's license or the author says it's okay. when that isn't clear, Branch links to the author's original release instead of hosting a copy.

Branch doesn't have a separate legal contact address yet. the report button is the way to reach the admin for now.
