# Privacy notice

last updated: october 29, 2026

Branch is run by Drifted (contact: drifted1000@outlook.com). this page explains what Branch actually collects. the short version: no accounts, no ads, no tracking.

## what stays on your computer

- **favorites, recently viewed mods and settings** (like dark mode) are saved inside the app on your computer. they never get sent to the server.
- you can clear them any time in Settings. uninstalling Branch removes them too.
- downloaded files go wherever you choose to save them. Branch doesn't keep a list of them after you close the app.

## what the server sees

when you use Branch, your computer connects to the Branch server to load the mod list, pictures and downloads. like any website, the server can see your IP address while it handles the request.

- **rate limits:** to stop spam and abuse, the server keeps a short-term counter for each visitor in memory. it uses a one-way scrambled (hashed) version of your IP address, not the address itself. these counters are gone when the server restarts.
- **download counts:** when you download a mod or open its download page through Branch, the server saves the hashed IP, the release and the date so each person only counts once per day. these records are deleted after 30 days. only the total number is kept.
- **server logs:** the Branch server logs things like the address that was requested, the result and how long it took, so problems can be fixed. it doesn't log passwords, report text or contact info. the hosting provider (Railway) may also keep its own network logs under its own policies.

Branch doesn't use analytics, advertising trackers or cookies in the desktop app.

## reports

if you report a mod, the server stores:

- which mod you reported and the reason you picked
- the details you wrote (optional)
- your contact info, only if you chose to add it
- a hashed version of your IP address (used for spam limits)
- the date and time

reports are private. only the Branch admin can see them. they are never shown in the app. a report is deleted 180 days after it's marked resolved or dismissed.

if you're under 13, please don't put contact info in a report.

## other websites

some mods link to the author's own page (like GitHub). when you open those, you're on their website and their privacy policy applies.

## contact and removal requests

for privacy questions, or to ask for a report you sent to be deleted, email **drifted1000@outlook.com**. say which mod you reported and roughly when, so the right report can be found.

## changes

if this notice changes, the date at the top will change too.
